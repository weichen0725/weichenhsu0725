# 小宸老師設計© 互動教材作品集

給特殊需求學生使用的 3D 情境模擬與互動練習網站。每個作品各放在一個資料夾，首頁 `index.html` 是作品目錄。

| 作品 | 資料夾 | 說明 |
| --- | --- | --- |
| 3D 生活管理小達人 | `life-management-3d/` | 自我照顧、家庭生活、社區參與、危機應變四個模組，練習工作分析步驟 |
| 時間小達人：我的生活任務 | `time-master/` | 一天的時段、整點與半點、60 秒體感、經過時間，全程語音報讀 |
| 句子積木工廠 | `sentence-blocks/` | 國小智障與學障學生的單句、複句練習：語法色彩積木、3D 情境動畫、口述成句、連環小日記 |

## 網址

開啟 GitHub Pages 後（Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)`），網站會在：

- 作品目錄：https://weichen0725.github.io/weichenhsu0725/
- 3D 生活管理小達人：https://weichen0725.github.io/weichenhsu0725/life-management-3d/
- 時間小達人：https://weichen0725.github.io/weichenhsu0725/time-master/
- 句子積木工廠：https://weichen0725.github.io/weichenhsu0725/sentence-blocks/

## 備註

- 3D 畫面使用 three.js（由 jsDelivr CDN 載入），需要連上網路。
- 星星、收藏、房間擺飾，以及句子積木工廠的學習紀錄與自訂題目，都存在每台裝置的瀏覽器裡，換裝置不會同步。
- 句子積木工廠的「口述成句」使用瀏覽器內建的語音辨識，第一次使用時瀏覽器會詢問麥克風權限。
